# Orlando & Mónica — Menu de Casamento

Website de seleção de comida e bebidas para o casamento de **Orlando Matumona & Mónica Matumona**.

## Estrutura

```text
casamento-orlando-monica/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── README.md
```

## Como executar

1. Abra a pasta no VS Code.
2. Abra `index.html` no navegador ou use a extensão Live Server.
3. O website é responsivo para computador, tablet e telemóvel.

## Funcionalidades

- Menu inspirado na Opção 2 — Menu de Luxo.
- Navegação com scroll suave.
- Menu mobile.
- Cartões para os pratos.
- Seleção de pratos, guarnições, cocktails e bebidas.
- Contador de itens selecionados.
- Área de confirmação da escolha.
- Layout responsivo.
- Estrutura pronta para integrar WhatsApp, email ou base de dados.

## Nota

As imagens utilizadas no protótipo são imagens externas de demonstração. Para a versão final, podem ser substituídas por fotografias reais dos pratos e bebidas do casamento.

A lista de bebidas alcoólicas ainda pode ser preenchida quando os nomes específicos forem definidos.
